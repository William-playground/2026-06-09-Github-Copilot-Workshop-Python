# ポモドーロタイマー 段階的実装計画

## 📋 段階的実装計画

### **フェーズ 1: Flask 基盤 + UI の骨組み（1-2 日）**

**目標**: ブラウザで UI モックのような画面を表示できる状態

**実装内容**:
- [ ] Flask アプリファクトリ形式の実装（`app.py`）
- [ ] HTML テンプレート (`templates/index.html`) - UI モックの HTML 構造を再現
- [ ] CSS スタイル (`static/css/style.css`) - UI モックの見た目を実装
  - 背景、ウィンドウカード、円形タイマーリング
  - ボタン、ステータス表示、進捗表示

**成果物**: `python app.py` で起動し、ブラウザに UI モックと同じ見た目が表示される

---

### **フェーズ 2: タイマーロジック（純粋関数）の実装（1-2 日）**

**目標**: ビジネスロジックを DOM に依存させず、テスト可能にする

**実装内容**:
- [ ] `static/js/timer-core.js` - 状態遷移のロジック
  - `createInitialState()` - 初期状態生成
  - `startTimer(state)` - タイマー開始
  - `pauseTimer(state)` - 一時停止
  - `resetTimer(state)` - リセット
  - `tick(state)` - 1 秒経過時の状態更新
  - `completeSession(state)` - セッション完了処理
  - `formatTime(seconds)` - 秒数を `25:00` 形式に変換
  - `getProgress(state)` - 円形進捗率の計算

**テスト**: 
- [ ] `tests/js/timer-core.test.js` - Vitest で単体テスト実装

**成果物**: DOM に触らない純粋な JavaScript ロジックがテスト可能な状態

---

### **フェーズ 3: UI 更新と基本イベント処理（1-2 日）**

**目標**: ボタンクリックでタイマーが動作する

**実装内容**:
- [ ] `static/js/timer-ui.js` - DOM 更新処理
  - 残り時間表示を更新
  - ステータスラベルを更新
  - 円形プログレスリングを更新
  - ボタン表示の切り替え（開始 → 一時停止）
  - 進捗表示（完了回数、集中時間）を更新

- [ ] `static/js/app.js` - イベント登録と統合
  - ボタンクリックリスナーの登録
  - `setInterval` でタイマー実行管理
  - `timer-core.js` と `timer-ui.js` の連携

**成果物**: ブラウザで「開始」「一時停止」「リセット」が動作し、画面がリアルタイムに更新される

---

### **フェーズ 4: ローカルストレージ統合（1 日）**

**目標**: ページをリロードしても進捗が保存される

**実装内容**:
- [ ] `static/js/storage.js` - localStorage 管理
  - `saveProgress(state)` - 進捗を保存
  - `loadProgress()` - 進捗を復元
  - `resetIfNewDay()` - 日付変更時のリセット

- [ ] `app.js` の更新 - storage との統合

**テスト**:
- [ ] `tests/js/storage.test.js` - localStorage の動作確認

**成果物**: ページをリロード後も「今日の進捗」が保存されている状態

---

### **フェーズ 5: テスト整備（1-2 日）**

**目標**: 各モジュールの動作が保証される

**実装内容**:
- [ ] `tests/test_app.py` - Flask ルーティングテスト
  - `GET /` が 200 を返す
  - HTML テンプレートが正しくレンダリングされる

- [ ] `tests/js/timer-core.test.js` の充実
  - 状態遷移テスト
  - 完了判定ロジック
  - フォーマット変換

- [ ] 必要に応じて `timer-ui.js` のテスト（jsdom 使用）

**成果物**: すべてのユニットテストが成功する状態

---

### **フェーズ 6: 機能拡張（オプション、2-3 日以上）**

**優先度の高い順**:

1. **休憩モード**
   - 作業完了後、自動的に休憩タイマーへ切り替え
   - `mode` に `break` を追加

2. **長い休憩**
   - 4 回完了ごとに 15 分の長い休憩

3. **設定画面**
   - 作業時間、休憩時間を変更可能

4. **通知機能**
   - セッション完了時に通知音や Notification API

5. **履歴 API**
   - Flask API を追加して日別の実績を保存（SQLite）
